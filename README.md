# DocSense

DocSense - backend-сервис для загрузки, хранения и дальнейшего интеллектуального анализа документов.

Цель проекта - упростить работу с документами: автоматически определять их тематику, сортировать по категориям, извлекать полезную информацию и отвечать на вопросы по содержимому.

## Текущее состояние

Сейчас реализована базовая работа с файлами:

- загрузка документа через API;
- сохранение файла в локальную папку `uploads`;
- защита от перезаписи файлов с одинаковыми именами;
- сохранение метаданных документа в SQLite;
- получение и скачивание документа по его ID;
- автоматическая документация API через Swagger UI.

AI-анализ и автоматическая сортировка пока находятся в планах развития.

## Установка

Клонируйте репозиторий и перейдите в папку проекта:

```bash
git clone https://github.com/skyland228/docsense.git
cd docsense
```

Создайте и активируйте виртуальное окружение:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Установите зависимости:

```powershell
pip install -r requirements.txt
```

## Запуск

```powershell
python -m docsense.main
```

После запуска приложение доступно по адресу:

- API: `http://127.0.0.1:8000`
- Swagger UI: `http://127.0.0.1:8000/docs`

## API

### Загрузить документ

```http
POST /api/v1/documents/upload
```

Запрос отправляется в формате `multipart/form-data`. Файл передаётся в поле `file`.

### Скачать документ

```http
GET /api/v1/documents/{document_id}/download
```

`document_id` - идентификатор документа, сохранённый в базе данных.

## Структура проекта

```text
docsense/
|-- api/            # HTTP-ручки
|-- data_base/      # подключение к БД и SQLAlchemy-модели
|-- repositories/   # запросы к базе данных
|-- services/       # бизнес-логика и работа с файлами
|-- dependencies.py # зависимости FastAPI
|-- schemas.py      # Pydantic-схемы
`-- main.py         # создание и запуск приложения
```
